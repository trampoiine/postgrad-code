# 智能驾舱线控底盘控制台 (PyQt5版) (v1.0)

**客户端名称：** 智能驾舱控制台 (PyQt5版)  
**版本号：** v1.0  
**目标协议：** 智能驾舱 CAN 总线通信协议（UDP 封装）  
**发送周期：** 10 ms（约 100 Hz）  

---

## 一、项目简介

本项目是一个基于纯 Python (PyQt5) 开发的上位机控制客户端，不依赖 Web 浏览器。用于向线控底盘发送控制指令（UDP封装CAN报文），并实时接收底盘回传的车辆状态。

核心功能：
- 方向盘转向控制（带 0.1° 精度转换与补码）
- 目标车速控制（车速模式：6~25 km/h）
- 制动踏板控制（0~100%）
- 档位切换（P / R / N / D，带跳变信号）
- 灯光与喇叭控制（转向灯、双闪、喇叭）
- 实时车速回传显示（解析 0x502 报文）
- 完整的安全联锁逻辑（车速不为 0 禁止换挡）
- 界面内置 Toast 提示框（换挡被拦截时弹窗提示）

## 四、运行方式

### 1. 本地无实车测试
如果你没接实车，想测试前端界面和逻辑：
1. 打开 `can_controller_gui.py`，确保 `HOST = "127.0.0.1"`。
2. 运行程序：
   ```powershell
   python can_controller_gui.py
   ```
3. **注意**：因为没接实车，界面的“实际车速”会一直显示 `--`。
4. **如何测试换挡安全锁**：为了在本地测试“车速不为0禁止换挡”，你可以在 `set_gear` 函数里临时把 `self.real_actual_speed` 强制设为 `5.0`，此时点档位就会弹窗拦截。

### 2. 实车联调测试（通过 CANET 网关）
**硬件准备：**
- 电脑网卡 IP 必须设置为 `192.168.1.110`，子网掩码 `255.255.255.0`。
- CANET 网关 IP 设为 `192.168.1.178`，启动网关转换。

**代码修改：**
1. 打开 `can_controller_gui.py`，修改目标 IP：
   ```python
   HOST = "192.168.1.178"
   ```
2. 运行 `python can_controller_gui.py`。

## 五、通信协议说明

### 1. 发送报文 (0x501) - 上位机 -> 底盘
- **CAN ID**: `0x501`
- **波特率**: 500k
- **帧格式**: 标准帧
- **周期**: 10ms

| 字节 | 含义 | 说明 |
|---|---|---|
| Byte0 | 控制使能 | 本系统固定发 `0x1F`（全使能，车速控制模式） |
| Byte1 | 目标车速 | 物理范围 `6~25` (km/h)，挂入 D/R 档时生效 |
| Byte2 | 方向盘角度高字节 | 左正右负，分辨率 `0.1°`（如左转20°发 200，即 `00 C8`） |
| Byte3 | 方向盘角度低字节 | 同上 |
| Byte4 | 制动踏板开度 | `0~100` (%) |
| Byte5 | 档位/灯光/喇叭 | Bit0~3:档位(1:R, 2:N, 3:D, 4:P)<br>Bit4~5:转向灯(1:关, 2:左, 3:右)<br>Bit6:双闪(0/1)<br>Bit7:喇叭(0/1) |
| Byte6 | 雨刷控制 | 本系统暂未使用，固定 `0x00` |
| Byte7 | 模式切换 | 启动时发 `0x02` (自动驾驶/座舱模式)，100ms后跳变回 `0x00` |

### 2. 接收报文 (0x502) - 底盘 -> 上位机
- **CAN ID**: `0x502`
- **说明**：底盘周期回传的车辆状态。
- **本系统解析**：通过 UDP 接收，解析 **Byte1** (`ActualMotoSpd`)，用于界面“实际车速”的显示。

## 六、核心安全逻辑

本系统严格遵守底盘控制安全规范，实现了以下保护机制：

1. **跳变信号 (Jump Signal) 机制**：
   档位、转向灯、模式切换属于“跳变信号”。PyQt5 使用了 `QTimer`（单次触发 100ms），到期后自动将对应位清零，完美还原真实拨杆的物理动作。
2. **车速不为 0 严禁换挡**：
   后台开辟了独立的 `recv_thread` 接收底盘数据。只要解析到“实际车速”大于 0，用户在界面点 P/R/N/D 档均会被拦截，并在屏幕中央弹出黑底白字警告。
3. **档位与速度联动**：
   当挂在 P 或 N 档时，界面上的“+”“-”目标车速按钮将被置灰禁用，防止误触。
4. **一键复位**：
   按下“全部复位”按钮，系统会切断动力（挂P档、踩刹车、速度归零、关闭所有灯光），并恢复初始状态。

## 七、常见问题排查

1. **界面报错缺少 PyQt5**：请确保在正确的 Python 环境中执行了 `pip install PyQt5`。
2. **实车完全没反应**：
   - 检查电脑 IP 是否改成了 `192.168.1.110`。
   - 检查代码里的 `HOST` 是否改成了 `192.168.1.178`。
   - 检查 CAN_H 和 CAN_L 是否接反。
   - 检查网关软件是否点击了“启动CAN”。
3. **实际车速一直显示 --**：
   - 确认底盘确实有发 `0x502` 报文。
   - 确认接收端口 `4001` 没被其他软件（如 CANTest）占用。
