# 智能驾舱线控底盘控制台 (v1.0)

**客户端名称：** 智能驾舱控制台客户端  
**版本号：** v1.0  
**目标协议：** 智能驾舱 CAN 总线通信协议（UDP 封装）  
**发送周期：** 10 ms（约 100 Hz）  

---

## 一、项目简介

本项目是一个基于 Python (pywebview) 和 HTML/JS 的上位机控制客户端。用于向线控底盘发送控制指令（UDP封装CAN报文），并实时接收底盘回传的车辆状态。

核心功能：
- 方向盘转向控制（带 0.1° 精度转换与补码）
- 目标车速控制（车速模式：6~25 km/h）
- 制动踏板控制（0~100%）
- 档位切换（P / R / N / D，带跳变信号）
- 灯光与喇叭控制（转向灯、双闪、喇叭）
- 实时车速回传显示（解析 0x502 报文）
- 完整的安全联锁逻辑（车速不为 0 禁止换挡）

## 四、运行方式

### 1. 本地假数据测试（无实车）
如果你没接实车，想测试前端界面和逻辑：
1. 打开 `main.py`，确保 `TARGET_IP = '127.0.0.1'`。
2. 确保 `recv_loop` 里的 `IS_SIMULATION = True`（这会模拟底盘回传真实车速）。
3. 运行：`python main.py`
4. 在界面挂入 D 档，你会发现“实际车速”开始跳动；此时尝试挂 P 档，系统会拦截并提示“换挡失败”。

### 2. 实车联调测试（通过 CANET 网关）
**硬件准备：**
- 电脑网卡 IP 必须设置为 `192.168.1.110`，子网掩码 `255.255.255.0`。
- CANET 网关 IP 设为 `192.168.1.178`，启动网关转换。

**代码修改：**
1. 打开 `main.py`，修改目标 IP：`TARGET_IP = '192.168.1.178'`
2. 关闭假数据模拟：`IS_SIMULATION = False`
3. 运行 `python main.py`。

## 五、通信协议说明

### 1. 发送报文 (0x501) - 上位机 -> 底盘
- **CAN ID**: `0x501`
- **波特率**: 500k
- **帧格式**: 标准帧
- **周期**: 10ms

| 字节 | 含义 | 说明 |
|---|---|---|
| Byte0 | 控制使能 | 本系统固定发 `0x1F`（全使能，车速控制模式） |
| Byte1 | 目标车速 | 物理范围 `6~25` (km/h)，挂入 D/R 档时生效 |
| Byte2 | 方向盘角度高字节 | 左正右负，分辨率 `0.1°`（如左转20°发 200，即 `00 C8`） |
| Byte3 | 方向盘角度低字节 | 同上 |
| Byte4 | 制动踏板控制（0~100%，支持一键归零）
| Byte5 | 档位/灯光/喇叭 | Bit0~3:档位(1:R, 2:N, 3:D, 4:P)<br>Bit4~5:转向灯(1:关, 2:左, 3:右)<br>Bit6:双闪(0/1)<br>Bit7:喇叭(0/1) |
| Byte6 | 雨刷控制 | 本系统暂未使用，固定 `0x00` |
| Byte7 | 模式切换 | 启动时发 `0x02` (自动驾驶/座舱模式)，100ms后跳变回 `0x00` |

### 2. 接收报文 (0x502) - 底盘 -> 上位机
- **CAN ID**: `0x502`
- **说明**：底盘周期回传的车辆状态。
- **本系统解析**：通过 UDP 接收，解析 **Byte1** (`ActualMotoSpd`)，用于界面“实际车速”的显示。

## 六、核心安全逻辑

本系统严格遵守底盘控制安全规范，实现了以下保护机制：

1. **跳变信号 (Jump Signal) 机制**：
   档位、转向灯、模式切换属于“跳变信号”。代码会在发送 `100ms` 后自动将这些字节清零（变回 `0x00`），完美还原真实拨杆的物理动作，防止总线阻塞报错。

2. **车速不为 0 严禁换挡**：
   只要收到底盘回传的“实际车速” `> 0`，无论是挂 P 档还是 R 档，后端都会拦截并向前端返回错误信息，防止打碎驻车棘爪或变速箱。

3. **档位与速度联动**：
   当挂在 P 或 N 档时，目标车速被强制锁定为 `0`，且界面上的加减速按钮会被禁用。

4. **一键复位**：
   按下“全部复位”按钮，系统会切断动力（挂P档、踩刹车、速度归零、关闭所有灯光），并恢复发送，防止失控。

5. **制动一键归零快捷操作**：
   在实车调试时，连续点击制动踏板减号效率极低。界面新增了“归零”按钮，可一键将制动踏板开度直接清零，方便车辆快速解除刹车限制恢复动力。

## 七、常见问题排查

1. **界面卡死或白屏**：可能缺少 WebView2 运行库，请前往微软官网下载安装。
2. **实车完全没反应**：
   - 检查电脑 IP 是否改成了 `192.168.1.110`。
   - 检查 `main.py` 里的 IP 是否改成了 `192.168.1.178`。
   - 检查 CAN_H 和 CAN_L 是否接反。
   - 检查网关软件是否点击了“启动CAN”。
3. **实际车速一直显示 `--`**：
   - 确认已经关闭了 `IS_SIMULATION`。
   - 底盘是否真在发 `0x502`？可在 CANTest 软件里看是否有报文。
